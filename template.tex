\begin{reportabstract}

Adding a mild calibration penalty improved macro F1 by 2.3 percentage
points while reducing calibration error. The gain was consistent in
four of five random seeds, but the rarest class remains unstable. Next
week's work will therefore focus on label quality and seed sensitivity.

\end{reportabstract}

\begin{pppbox}{Progress}

\ReportSubsection{Loss Formulation and Working Interpretation}

The baseline was extended with a Brier-style calibration term,

\[
    \mathcal{L}
    = \mathcal{L}_{\mathrm{CE}}
    + \frac{\lambda}{N}
      \sum_{i=1}^{N}\left\lVert\mathbf{p}_i-\mathbf{y}_i\right\rVert_2^2,
\]

where $\lambda$ controls the trade-off between discrimination and
calibration. A short sweep suggested the following interpretation:

\begin{itemize}
    \item $\lambda=0.05$ improved calibration without reducing accuracy.
        \begin{itemize}
            \item Larger values produced under-confident predictions.
            \item The effect was strongest for examples near class boundaries.
        \end{itemize}
    \item Data splits and preprocessing were held fixed across methods.
\end{itemize}


\ReportSubsection{Quantitative Comparison}

As shown in \cref{tab:main-results}, the moderate penalty gave the best
overall balance. The stronger penalty minimized ECE but lost part of the
rare-class gain, suggesting that calibration alone is not the objective.


\ReportSubsection{Implementation and Supporting Work}

    \item Built an error-analysis notebook grouped by class and confidence.
    \item Reviewed two calibration studies and recorded why temperature
          scaling was deferred until after the label audit.
\end{itemize}

\begin{pppbox}{Problems}

\ReportSubsection{Rare-Class Instability}

Worst-class F1 still varied by 7.8 points across seeds, so the apparent
gain is not yet strong enough to support a general conclusion.

\begin{itemize}
    \item \textbf{Working hypothesis:} a small cluster of inconsistently
          labeled samples changes the decision boundary between splits.
    \item \textbf{Attempts and evidence:} class weighting reduced mean
          performance, while manual inspection found three ambiguous samples.
    \item \textbf{Next response:} audit the rare-class labels and repeat the
          comparison with stratified seeds and confidence intervals.
\end{itemize}


\ReportSubsection{Primary Metric Requires a Decision}

This is a decision problem rather than one with a causal hypothesis.
Macro F1 communicates class balance, whereas ECE better reflects the
deployment risk. Advisor feedback is needed on which should be the primary
claim; both metrics will remain reported regardless of that decision.

\end{pppbox}
