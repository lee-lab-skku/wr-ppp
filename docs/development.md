# Development Guide

This guide routes contributors to shared architecture, implementation contracts, documentation maintenance, and validation.
Start with [CONTRIBUTING.md](../CONTRIBUTING.md) for development setup and the contribution workflow.

## Responsibilities

[Shared Architecture](development/architecture.md) defines source ownership, repository files, editor boundaries, and command entry-point contracts.
Use it to place implementation and preserve the shared responsibilities of the Docker and native Windows workflows.

## Markdown Structure

[Documentation Maintenance](development/documentation.md) explains how to follow mddt's writing procedure, from placing content before writing to rereading changed topics.
Its automated checker verifies only deterministic minimum requirements alongside author and reviewer judgment.

## Shell and Build Safety

[Shell and Build Contracts](development/build-contracts.md) defines portability, setup transactions, build isolation, and safe PDF publication.

<a id="automatic-updates"></a>
The same reference covers [automatic-update safeguards](development/build-contracts.md#automatic-updates), including version selection and installation locking.

## Editing AI Skills

Use [Documentation Maintenance](development/documentation.md) for the reference order, ownership boundaries, and preservation requirements when editing bundled skills.
The skill entry points route tasks to canonical procedures while keeping shared policy in its owning documents.

## Validation

[Development Validation](development/validation.md) gives the checks for report guidance, editor behavior, and common or administrator workflows.
It also defines how to report unperformed checks and environment limits.

## Documentation and Scope

[Documentation Maintenance](development/documentation.md) defines document roles and the external perspective used for Windows in shared guides.
[Administrator Development](admin-development.md) owns administrator implementation contracts; the skill references own operating procedures and formats.
